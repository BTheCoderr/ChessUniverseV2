# App Store screenshot attempt

This folder does not contain verified native iOS screenshots.

This environment is Linux and has no iOS Simulator or Xcode, so the Expo app in `apps/mobile` could not be launched. The images were captured with Playwright from the local website at `http://127.0.0.1:5173/` on November 17, 2026.

## What is real

`web-captures/` are unmodified browser screenshots. The viewport is the iPhone 6.9-inch App Store size, 1320 by 2868 pixels. Each image shows a screen that was actually open:

- Home
- Practice, with the real board and Black to move
- Academy section list
- Puzzles, including this browser's real zero progress
- Legends, including The Immortal Game
- Online, signed out

No player counts, ratings, or lesson statistics were added.

`branded-from-web-captures/` places those same screenshots on the midnight navy background with the real gold knight logo. The headlines are words already shown by the website. Every branded file is marked "WEBSITE CAPTURE".

## Not ready for App Store Connect

Do not upload these as iPhone or iPad screenshots for the native app. The iOS home screen is a different interface from this website, and no iPad simulator was available. Apple's iOS slots need captures from the installed iPhone app or an iOS Simulator.
